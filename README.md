# hxyfront-62009 手工地毯修复工作室 · 纹样档案与补线库存

给手工地毯修复工作室使用的单页应用：管理地毯档案、纹样破损标记、修复工序进度和材料色卡库存。数据保存在浏览器 localStorage，无需后端。

## 功能

### 地毯档案
- 录入产地、年代、结密度（结/dm² 或 kpsi）、材质、染色方式、破损区域
- 上传纹样局部图并在图上点击打破损标记（按百分比定位，图片缩放不错位），可逐个删除
- 修复前 / 修复后备注（完工时可直接回填到档案）
- 档案列表按产地筛选（带数量），支持关键字搜索，详情页展示相关工序

### 修复工序（看板：草稿 / 在制 / 完工 / 已撤单）
- 新增工序时从材料色卡选补线、填用量，实时显示当前可用余量
- **开工先占线**：校验可用库存，把补线预留出来（账面库存不变，只增加占用）
- **完工再扣库存**：按实际用量从账面扣除并释放占用，同时回填修复后备注
- **撤单放回**：不扣库存，占用量全部放回对应色卡
- 库存不足时禁止开工；草稿不占库存，可随意增删改

### 材料色卡
- 账面库存 = 可用余量 + 在制占用；支持采购入库、盘点盘盈/盘亏（占用部分不可盘亏）
- 色名 / 色号可随时修改：**旧工序永久保留开工当时的旧色名与旧色号**（卡片带「旧名」标记），库存与流水仍按色卡本体结算
- 全量库存流水：入库、占线、完工扣库、撤单放回、盘点调整，逐笔可查
- 有在制占用或草稿引用的色卡禁止删除

## 库存模型

| 动作 | 账面库存 stock | 在制占用 held |
| --- | --- | --- |
| 开工占线 | 不变 | +用量 |
| 完工扣库 | −用量 | −用量 |
| 撤单放回 | 不变 | −用量 |
| 采购入库 | +数量 | 不变 |
| 盘点调整 | ±数量 | 不变 |

可用余量 = stock − held；开工前逐行校验「当前占用 + 本单用量 ≤ 账面库存」。

## 技术栈

React 19 + Vite 7 + TypeScript，数据持久化用 localStorage。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62009

首次打开自带演示数据（含已改名色卡的旧工序快照、占线/扣库/放回各类流水），可在右上角「恢复演示数据」重置。
